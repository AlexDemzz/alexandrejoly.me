The **breakpoint** is fixed at 768px, read through the shadcn `use-mobile` hook, the same one the Sidebar uses. At 768px and up the desktop component renders, below it the mobile one. This is a conditional render, not CSS: only one side is mounted at a time.

## What carries over

Every responsive component holds the open state itself, so an uncontrolled overlay that is open stays open across 768px. State held _inside_ the overlay does not carry over: uncontrolled form fields reset. Keep values you cannot afford to lose in your own state or a form library.

## Opening on load

The first render, before the viewport is known, is the desktop side. A `defaultOpen` overlay on a phone therefore flashes as the desktop component before it becomes a drawer. To open on load without that flash, control `open` and set it after mount.
