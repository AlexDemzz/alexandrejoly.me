---
title: DialogDrawer
description: A centered Dialog at desktop that becomes a swipeable Drawer below 768px.
---

A drop-in replacement for the shadcn [Dialog](https://ui.shadcn.com/docs/components/dialog): at 768px and up it renders your Dialog unchanged; below, the same children render inside your [Drawer](https://ui.shadcn.com/docs/components/drawer).

  <ComponentDemoRender>
    <DialogDrawerPreview />
  </ComponentDemoRender>
  <ComponentDemoCode>

```tsx
import { useState } from "react";

import {
  DialogDrawer,
  DialogDrawerContent,
  DialogDrawerDescription,
  DialogDrawerFooter,
  DialogDrawerHeader,
  DialogDrawerTitle,
  DialogDrawerTrigger,
} from "@/components/ui/dialog-drawer";

export function EditProfile() {
  // Above DialogDrawer, so the name survives crossing 768px.
  const [name, setName] = useState("Jordan Lee");

  return (
    <DialogDrawer>
      <DialogDrawerTrigger>Edit profile</DialogDrawerTrigger>
      <DialogDrawerContent
        className="sm:max-w-sm"
        drawer={{ className: "sm:max-w-none" }}
      >
        <DialogDrawerHeader>
          <DialogDrawerTitle>Edit profile</DialogDrawerTitle>
          <DialogDrawerDescription>
            Change the name shown on your profile.
          </DialogDrawerDescription>
        </DialogDrawerHeader>
        <form className="grid gap-4 p-4 md:p-0">
          <label htmlFor="name">Name</label>
          <input
            id="name"
            value={name}
            onChange={(event) => setName(event.target.value)}
          />
        </form>
        <DialogDrawerFooter showCloseButton />
      </DialogDrawerContent>
    </DialogDrawer>
  );
}
```

  </ComponentDemoCode>
</ComponentDemo>

## Installation

```bash
npx shadcn@latest add @alexandrejoly/dialog-drawer
```

## Migrating

Rename as in [Migrating](/docs/installation#migrating), then check below 768px: [Content width](#sizing-classes), [body padding](#body-padding) and [desktop-only props](#desktop-only-props).

## Sizing classes

The `className` on `DialogDrawerContent` applies to both sides. A width such as `sm:max-w-sm`, from the shadcn Dialog examples, starts at 640px, below the breakpoint, so it also narrows the drawer on large phones and small tablets. Reset it in the override with the same `sm:` prefix, since `cn` only replaces a class with the same prefix, or write the width with `md:`:

<ComponentDemo>
  <ComponentDemoRender>
    <DialogDrawerSizingExample />
  </ComponentDemoRender>
  <ComponentDemoCode>

```tsx
<DialogDrawerContent
  className="sm:max-w-sm"
  drawer={{ className: "sm:max-w-none" }}
>
```

The Dialog pads its whole content box; the Drawer pads only its header and footer. Give the body between them its own padding below 768px:

## `onOpenChange`

`onOpenChange` on the root has your Dialog's signature and also fires below 768px, so `onOpenChange={setOpen}` works on both sides. Below 768px it can receive reasons only the Drawer has, such as `"swipe"`, which the Dialog's types do not list. To act on them, use the Drawer's own handler, which runs after the shared one:

<ComponentDemo>
  <ComponentDemoRender>
    <DialogDrawerSwipeReasonExample />
  </ComponentDemoRender>
  <ComponentDemoCode>

```tsx
<DialogDrawer
  onOpenChange={setOpen}
  drawer={{
    onOpenChange: (open, eventDetails) => {
      if (eventDetails.reason === "swipe") {
        // below 768px only, after the shared handler
      }
    },
  }}
>
  {/* … */}
</DialogDrawer>
```

  </ComponentDemoCode>
</ComponentDemo>

## Desktop-only props

Dropped below 768px:

- **`showCloseButton` on the Content.** `showCloseButton` on the Footer works on both sides.
- **[Detached triggers](/docs/override-prop#shared-root) on Base UI.**

## Nested dialogs

A `DialogDrawer` inside another one renders a drawer inside a drawer below 768px.

## API reference

Each part takes every prop of its shadcn Dialog counterpart, plus a `drawer` prop that takes the props of the matching Drawer part, except `children`. Only the parts below leave out more (see [Shared root](/docs/override-prop#shared-root)).

### DialogDrawer

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof Drawer>, "children" \| RootState>` | - |

### DialogDrawerTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof DrawerTrigger>, "children" \| "handle" \| "payload">` | - |

## Radix notes

- `drawer={{...}}` is typed on Vaul.
- The drawer moves focus inside when it opens. Pass `drawer={{ autoFocus: false }}` to turn that off.
