A drop-in replacement for the shadcn [Popover](https://ui.shadcn.com/docs/components/popover): at 768px and up it renders your Popover unchanged; below, the same children render inside your [Drawer](https://ui.shadcn.com/docs/components/drawer).

```tsx
import { useState } from "react";

import {
  PopoverDrawer,
  PopoverDrawerContent,
  PopoverDrawerDescription,
  PopoverDrawerHeader,
  PopoverDrawerTitle,
  PopoverDrawerTrigger,
} from "@/components/ui/popover-drawer";

export function Dimensions() {
  // Above PopoverDrawer, so the values survive crossing 768px.
  const [width, setWidth] = useState("100%");
  const [height, setHeight] = useState("25px");

  return (
    <PopoverDrawer>
      <PopoverDrawerTrigger>Open popover</PopoverDrawerTrigger>
      <PopoverDrawerContent className="w-80">
        <PopoverDrawerHeader>
          <PopoverDrawerTitle>Dimensions</PopoverDrawerTitle>
          <PopoverDrawerDescription>
            Set the dimensions for the layer.
          </PopoverDrawerDescription>
        </PopoverDrawerHeader>
        <div className="grid gap-2">
          <div className="grid grid-cols-3 items-center gap-4">
            <label htmlFor="width">Width</label>
            <input
              id="width"
              value={width}
              onChange={(event) => setWidth(event.target.value)}
              className="col-span-2"
            />
          </div>
          <div className="grid grid-cols-3 items-center gap-4">
            <label htmlFor="height">Height</label>
            <input
              id="height"
              value={height}
              onChange={(event) => setHeight(event.target.value)}
              className="col-span-2"
            />
          </div>
        </div>
      </PopoverDrawerContent>
    </PopoverDrawer>
  );
}
```

## Installation

```bash
npx shadcn@latest add @alexandrejoly/popover-drawer
```

## Migrating

Rename as in [Migrating](/docs/installation#migrating), then check below 768px: the [desktop-only props](#desktop-only-props), and a title on every content (see [Accessibility](#accessibility)).

## The content box

Below 768px, `PopoverDrawerContent` wraps its children in a padded box with the Popover's column layout, so children written for the Popover render the same way in the Drawer. The `className` you pass to `PopoverDrawerContent` styles that box; `drawer={{ className }}` styles the drawer itself:

<ComponentDemo>
  <ComponentDemoRender>
    <PopoverDrawerContentBoxExample />
  </ComponentDemoRender>
  <ComponentDemoCode>

```tsx
<PopoverDrawerContent className="w-80" drawer={{ className: "max-h-[80dvh]" }}>
```

  </ComponentDemoCode>
</ComponentDemo>

A width such as `w-80` therefore sizes the content, centered in a full-width drawer, instead of shrinking the drawer to a 320px panel. `PopoverDrawerHeader` and `PopoverDrawerFooter` take their spacing from that box, as they do in the Popover.

## The `modal` default

With no `modal` prop, each side keeps its own default. Set `modal` to apply it to both sides, or `drawer={{ modal }}` to change only the drawer:

## The footer part

The shadcn Popover has no footer, but a drawer often needs an action row. `PopoverDrawerFooter` is optional: a `flex justify-end gap-2` row at 768px and up, your `DrawerFooter` below. To close from a button inside it, control `open`:

<ComponentDemo>
  <ComponentDemoRender>
    <PopoverDrawerFooterExample />
  </ComponentDemoRender>
  <ComponentDemoCode>

```tsx
const [open, setOpen] = React.useState(false)

<PopoverDrawer open={open} onOpenChange={setOpen}>
  <PopoverDrawerTrigger>Filters</PopoverDrawerTrigger>
  <PopoverDrawerContent>
    {/* … */}
    <PopoverDrawerFooter>
      <button type="button" onClick={() => setOpen(false)}>
        Apply
      </button>
    </PopoverDrawerFooter>
  </PopoverDrawerContent>
</PopoverDrawer>
```

## Desktop-only props

Dropped below 768px, because a drawer has no equivalent:

- **Positioning on the Content:** `side`, `align`, `sideOffset`, `alignOffset`, and on Radix the rest of the Popper props (`avoidCollisions`, `collisionPadding`, `sticky`, …).
- **Hover on the Trigger:** `openOnHover`, `delay`, `closeDelay`.
- **[Detached triggers](/docs/override-prop#shared-root) on Base UI.**
- **Anchoring on Radix:** `PopoverDrawerAnchor` renders your `PopoverAnchor` at 768px and up. Below 768px it renders its child (with `asChild`) or a plain `div`.

## Accessibility

Below 768px the content is a dialog, and a dialog needs a name. A popover without a title gets none: add a `PopoverDrawerTitle`, visually hidden if the design has no heading.

## API reference

Each part takes every prop of its shadcn Popover counterpart, plus a `drawer` prop that takes the props of the matching Drawer part, except `children`. Only the parts below leave out more (see [Shared root](/docs/override-prop#shared-root)).

### PopoverDrawer

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof Drawer>, "children" \| RootState>` | - |

`RootState` stands for the keys that `drawer` leaves out because they belong to the shared root: `open` and `defaultOpen`, since both sides share one open state, and the detached-trigger props `handle`, `triggerId` and `defaultTriggerId`. `drawer.onOpenChange` runs after the shared `onOpenChange` and receives your Drawer's own arguments.

### PopoverDrawerTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof DrawerTrigger>, "children" \| "handle" \| "payload">` | - |

### PopoverDrawerFooter

Optional. Takes every prop of a `div`, plus `drawer` with your `DrawerFooter` props, except `children`.

### PopoverDrawerAnchor

Radix only, optional. Takes every prop of your `PopoverAnchor` and adds none.

## Radix notes

- `drawer={{...}}` is typed on Vaul.
- The drawer moves focus inside when it opens. Pass `drawer={{ autoFocus: false }}` to turn that off.
