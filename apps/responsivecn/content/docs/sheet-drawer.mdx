title: SheetDrawer
description: An edge-anchored Sheet at desktop that becomes a swipeable Drawer below 768px.
---

A drop-in replacement for the shadcn [Sheet](https://ui.shadcn.com/docs/components/sheet): at 768px and up it renders your Sheet unchanged; below, the same children render inside your [Drawer](https://ui.shadcn.com/docs/components/drawer), anchored to the edge you set with `side`.

```tsx
import {
  SheetDrawer,
  SheetDrawerClose,
  SheetDrawerContent,
  SheetDrawerDescription,
  SheetDrawerFooter,
  SheetDrawerHeader,
  SheetDrawerTitle,
  SheetDrawerTrigger,
} from "@/components/ui/sheet-drawer";

export function WorkspaceMenu() {
  return (
    <SheetDrawer>
      <SheetDrawerTrigger>Open menu</SheetDrawerTrigger>
      <SheetDrawerContent side="right">
        <SheetDrawerHeader>
          <SheetDrawerTitle>Workspace</SheetDrawerTitle>
          <SheetDrawerDescription>
            Go to any page in this workspace.
          </SheetDrawerDescription>
        </SheetDrawerHeader>
        <nav>
          {["Dashboard", "Projects", "Members", "Settings"].map((item) => (
            <button key={item} type="button">
              {item}
            </button>
          ))}
        </nav>
        <SheetDrawerFooter>
          <SheetDrawerClose>Close</SheetDrawerClose>
        </SheetDrawerFooter>
      </SheetDrawerContent>
    </SheetDrawer>
  );
}
```

  </ComponentDemoCode>

## Installation

```bash
npx shadcn@latest add @alexandrejoly/sheet-drawer
```

## Migrating

Rename as in [Migrating](/docs/installation#migrating), then check below 768px: [Content width](#sizing-classes), and sheets that close only through the built-in close button or open from detached triggers (see [Desktop-only props](#desktop-only-props)).

## The drawer edge

`SheetDrawerContent` passes its `side` up to the root, so below 768px the drawer opens from the same edge and swipes the same way. This works wherever the Content sits: inside a Fragment, behind a condition or in your own component.

  <ComponentDemoCode>

```tsx
<SheetDrawer>
  <SheetDrawerTrigger>Open menu</SheetDrawerTrigger>
  {/* a left Sheet at 768px and up, a left Drawer below */}
  <SheetDrawerContent side="left">{/* … */}</SheetDrawerContent>
</SheetDrawer>
```

Without `side`, the Sheet and the Drawer each keep their default edge. Write `side="right"` to get a right drawer too.

To pick another edge below 768px only, set it on the root override. It wins over `side`:

```tsx
<SheetDrawer drawer={{ swipeDirection: "down" }}>
  {/* a left Sheet at 768px and up, a bottom Drawer below */}
  <SheetDrawerContent side="left">{/* … */}</SheetDrawerContent>
</SheetDrawer>
```

## Sizing classes

The `className` on `SheetDrawerContent` applies to both sides. Your Sheet sets its width under a `data-[side=…]` prefix, such as `data-[side=right]:sm:max-w-sm`, so widen it with the same prefix: `cn` replaces the matching class, and the drawer, which has no `data-side`, ignores it. A width without that prefix, such as `w-[400px]`, also narrows the drawer below 768px. Write it as `md:w-[400px]` instead.

## Desktop-only props

Dropped below 768px:

- **`showCloseButton` on the Content.** If the built-in button is your only way to close the sheet, add a `SheetDrawerClose`.
- **[Detached triggers](/docs/override-prop#shared-root) on Base UI.**

## Nested sheets

A `SheetDrawer` inside another one renders a drawer inside a drawer below 768px.

## API reference

Each part takes every prop of its shadcn Sheet counterpart, plus a `drawer` prop that takes the props of the matching Drawer part, except `children`. Only the parts below leave out more (see [Shared root](/docs/override-prop#shared-root)).

### SheetDrawer

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof Drawer>, "children" \| RootState>` | - |

### SheetDrawerTrigger

| Prop | Type | Default |
| --- | --- | --- |
| `drawer` | `Omit<ComponentProps<typeof DrawerTrigger>, "children" \| "handle" \| "payload">` | - |

## Radix notes

- `drawer={{...}}` is typed on Vaul. The edge for below 768px only is `drawer={{ direction }}`.
- The drawer moves focus inside when it opens. Pass `drawer={{ autoFocus: false }}` to turn that off.
