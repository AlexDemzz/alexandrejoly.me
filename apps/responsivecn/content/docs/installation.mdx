Responsive components install into a shadcn project on Base UI or Radix (see [Bases](/docs#bases)).

## Add a component

The components ship from the `@alexandrejoly` registry, listed in the shadcn registry directory, so no setup is needed. To pin it anyway, see [namespaced registries](https://ui.shadcn.com/docs/registry/namespace#configuration).

```bash
npx shadcn@latest add @alexandrejoly/dialog-drawer
```

It also installs the stock shadcn items it builds on (`dialog`, `drawer`, `use-mobile`, …) as registry dependencies, not copies.

## Migrating

A responsive component takes the desktop component's props 1:1, on the root and on every part. Change the imports and the tag names, nothing else:

```diff
- import { Dialog, DialogTrigger, DialogContent } from "@/components/ui/dialog"
+ import { DialogDrawer, DialogDrawerTrigger, DialogDrawerContent } from "@/components/ui/dialog-drawer"
```

Each part name inserts the mobile side's name after the desktop one: `DialogContent` becomes `DialogDrawerContent`. Same props, same children.
